Proyectos que hemos construido

Dos productos reales: una plataforma web de citas para estudios de tatuaje y una app móvil de servicios médicos a distancia.

Web · API REST · Live demo

AppointGo / Ink API

Sistema de gestión de citas para estudios de tatuaje. API REST con .NET 9 y Clean Architecture (estilo Milan Jovanović), frontend desplegado y listo para usar.

.NET 9EF CoreMediatRFluentValidation JWTGoogle OAuthGoogle CalendarSQL Server / Postgres

Abrir demo en vivo →

Flujo del cliente

  • Ve página pública (ubicación, galería)
  • Inicia sesión con Google OAuth → se registra como CLIENT
  • Selecciona staff + tamaño del tatuaje (SMALL / MEDIUM / LARGE)
  • Consulta disponibilidad en calendario y reserva horario
  • Se crea evento en Google Calendar (cliente + staff)

Flujo del staff

  • Listado de citas (nombre, hora, sucursal, tamaño, estado)
  • Configura tiempos por tamaño y bloquea horarios
  • Citas sincronizadas a su Google Calendar

Flujo del admin

  • Panel global de citas, reprogramar y reasignar staff
  • Vista de staff libres / sin citas
Android · React Native · Expo

App de Servicios Médicos a Distancia

Aplicación móvil completa para consultas virtuales, recetas electrónicas, historial médico digital y comunicación en tiempo real con médicos y especialistas.

React NativeExpoFirebase AuthFirestore Realtime DBSQLiteGoogle MapsPush Notifications

Funcionalidades de usuario

  • Autenticación segura con Firebase y encriptación de datos sensibles
  • Perfil completo y dashboard de consultas, recetas y mensajes
  • Búsqueda de médicos por especialidad, ubicación, disponibilidad e idioma
  • Programación y gestión de citas virtuales
  • Recetas electrónicas: ver, descargar y compartir con farmacias
  • Historial médico digital (consultas, recetas, resultados)

Comunicación y mapas

  • Chat en tiempo real con Firebase Realtime Database
  • Notificaciones push para mensajes y recordatorios
  • Google Maps, geolocalización y navegación a centros médicos
  • Foro de salud y sistema de calificaciones

Seguridad

  • Expo Secure Store y Crypto para datos sensibles
  • Validación de entrada y autenticación Firebase
